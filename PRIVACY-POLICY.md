# Privacy Policy

ABSTV is an unofficial Roku client for connecting to an Audiobookshelf server that you provide.

## Data You Enter

ABSTV asks for your Audiobookshelf server URL, username, and password so it can sign in to your server. The app sends those credentials only to the Audiobookshelf server URL that you enter.

## Data Stored On Your Roku Device

ABSTV stores session information on your Roku device so you do not need to sign in every time you open the app. This includes your server URL, username, authentication token, and application  settings.

Your Audiobookshelf password is not stored after sign-in. If you log out, ABSTV clears the saved session information used by the app.

## Data Sent To Your Audiobookshelf Server

ABSTV communicates with your configured Audiobookshelf server to load libraries, audiobook metadata, covers, chapters, playback sessions, and playback progress. This includes audiobook titles, authors, descriptions, cover requests, playback position, and other metadata returned by your server.

ABSTV does not send this information to any server other than the Audiobookshelf server URL that you configure.

## Diagnostics And Logs

ABSTV writes diagnostic information to the Roku debug log while the app is running. Logs can include request URLs, status messages, cache sizes, playback details, and error information useful for troubleshooting.

These logs stay on your Roku device unless you or a developer with access to your Roku debugging session views or shares them.

## Third Parties

ABSTV does not sell personal information, does not use advertising trackers, and does not send analytics to third-party services.

Your Audiobookshelf server is operated by you or by whoever provides the server you choose to use. Data handled by that server is governed by that server's configuration and policies.

## Contact

For questions about this privacy policy, contact the maintainer or publisher of the ABSTV Roku channel.
