# ABSTV

This is a Roku app that connects to an Audiobookshelf server to play audiobooks.

## AI Usage
This is my second app built entirely using AI.

The first AI coded app I created [synology-nut-api](https://github.com/thedavidhoffman/synology-nut-api) was a very successful endeaver. The intital project created by the AI was a fully functional node.js app that did everything I asked it to. Over the course of two days I steered the AI to bring that app into line with my standards, and also adding in the enhancements I felt it needed as the design evolved. Overall, AI did a great job and since I was already familiar with node.js I could easily understand and manage the code the AI was generating.

This app was a different story. The AI did a horrible job creating the UI for a Roku app, and didn't employ any SOLID principles. The code was very messy compared to the node.js app I spoke of. I've tried before to write a Roku app and it's a feral beast to tame. Developing for Roku has a pretty steep learning curve. But AI was generally able to understand the core Roku functionality, something I gave up attempting to understand with my first attempt at writing a Roku app. But the code and UI took much more effort to get in-line. Partly due to my lack of knowledge with the Roku development platform, but also because I have to think that the material for coding a Roku app, that's available to train an AI, is substantially less than information on building a node.js app and an html widget that it served.

All that being said. This app would not have been possible without the help of AI. Well, it would have been if I committed to MANY, MANY more weeks/months of learning all the ins/outs of Roku.
